## 1. 项目简介

**GearAutoOpt** 是在 FastCAE 上扩展的齿轮参数化自动化分析模块，实现从参数输入到有限元求解、再到多目标优化的完整闭环：

```
齿轮参数 → OCC 参数化建模 → Gmsh 网格 → CalculiX FEA → 应力/质量提取
                                                          ↓
                          Pareto 前沿 ← NSGA-II 多目标优化 ←
```

**核心功能**：

| 功能 | 说明 |
|------|------|
| 参数化建模 | 渐开线标准/变位齿轮对，支持修型，OCC 实体，自动打面语义标签 |
| 自动网格 | Gmsh C3D10 二次四面体，自动设置网格尺寸 |
| 自动求解 | 调用 CalculiX 进程外求解，提取齿根 von Mises 应力与最大位移 |
| 多目标优化 | NSGA-II（最小化应力 + 最小化质量），含约束处理与修复 |
| 结果持久化 | SQLite 数据库 + CSV/Excel 导出 |
| 结果可视化 | Pareto 散点图、全代历史表格、几何加载预览 |

1. 环境变量 `CCX_PATH`
2. `tools/calculix/ccx.exe`（相对于项目根）
3. 系统 `PATH`

## 5. 齿轮参数化建模

### 5.1 打开建模对话框

FastCAE 主菜单：**几何 → 创建齿轮**，弹出"创建齿轮"对话框。

### 5.2 参数说明

| 参数 | 说明 |
|------|------|
| **名称** | 留空自动生成 `Gear_N` |
| **模数 m** | 单位 mm，推荐标准值：1.5 / 2 / 2.5 / 3 / 4 |
| **齿数 Z₁** | 主动轮，建议 ≥ 17（避免根切） |
| **齿数 Z₂** | 从动轮 |
| **压力角 α** | 标准 20°，可选 22.5° / 25° |
| **齿顶高系数** | 外齿轮 1.0，内齿轮 0.6 |
| **齿根高系数** | 标准 1.25 |
| **圆角系数** | 标准 0.38 |
| **齿宽 B₁ / B₂** | 主/从动轮轴向厚度，单位 mm |
| **变位系数 x₁ / x₂** | 正变位增大齿根厚度；建议 |x| ≤ 0.8 防止齿顶变尖 |
| **齿顶修型量 Cₐ₁ / Cₐ₂** | 抛物线修型幅值，mm（0 = 不修型） |
| **修型长度 Lₐ₁ / Lₐ₂** | 从齿顶向下的修型区长度，mm |
| **齿轮类型** | 外齿轮 / 内齿轮 |

### 5.3 生成流程

点击**确认**后：

```
读取所有 UI 参数
    │
    ├─ 创建 GeoCommandCreateGear 命令对象
    ├─ buildGearProfileWire(Z₁) → 主动轮渐开线 Wire（50点/齿段）
    ├─ buildGearProfileWire(Z₂) → 从动轮渐开线 Wire（偏移到中心距处）
    ├─ extrudeProfile(wire1, holeWire1, B₁) → 主动轮 3D 实体
    ├─ extrudeProfile(wire2, holeWire2, B₂) → 从动轮 3D 实体
    ├─ tagGearFaces(set1) → 面语义标签
    │   └─ hub_hole / tooth_flank / root_fillet / front_face / back_face
    ├─ tagGearFaces(set2)
    └─ 两个独立 GeometrySet 加入几何树，视口显示
```

中心距由变位量自动计算（变位中心距公式）：

```
a' = (Z₁+Z₂)·m/2 · cos(α) / cos(α')
```

生成结果为**两个独立 GeometrySet**（`Gear_1` + `Gear_2`），不做 Boolean Fuse，便于分别施加边界条件。

### 5.4 编辑已有齿轮

几何树中右键 GeometrySet → **编辑**，对话框自动读取全部历史参数，修改后重新生成。

## 6. 单工况求解流程

### 6.1 工作目录

每次求解在独立子目录下执行：

```
runs/{generation}_{point_id}/      例：runs/0_003/
    ├── mesh.inp                    Gmsh 生成（节点 + C3D10 单元）
    ├── nset_hub.inp                内孔边界节点集
    ├── nset_tooth_face.inp         齿面加载节点集
    ├── elset_root.inp              齿根单元集（应力提取区域）
    ├── job.inp                     CalculiX 主控卡片
    ├── job.dat                  ← 应力结果（文本）
    ├── job.frd                  ← 全场结果（位移+应力）
    └── job.sta                  ← 收敛状态
```

### 6.2 执行步骤

```
① 几何生成
   GeoCommandCreateGear::execute() → TopoDS_Shape

② 网格划分
   Gmsh 对实体划 C3D10 二次四面体网格 → mesh.inp

③ 节点分类（按径向距离）
   r ≤ holeR × 1.1            → nset_hub（固定约束）
   r ≥ pitchR × 0.7, θ∈[60°,120°] → nset_tooth_face（切向载荷）

④ 输入卡生成
   CCXInpWriter → job.inp
   （含：*INCLUDE / *BOUNDARY / *CLOAD / *MATERIAL / *STEP）

⑤ CalculiX 求解
   CCXSolverController 启动 ccx.exe job
   等待结束（默认超时 600 s）

⑥ 结果提取
   CCXResultParser::parseDat("job.dat", "ELSET_ROOT")
   → sigmaMax [MPa]，uMax [mm]
   质量：mass = ρ · π · (R_tip² − R_hub²) · B  [kg]

```

### 6.3 材料参数（45# 钢，默认值）

| 参数 | 值 |
|------|----|
| 弹性模量 E | 2.06 × 10⁵ MPa |
| 泊松比 ν | 0.30 |
| 密度 ρ | 7.85 × 10⁻⁹ t/mm³ |
| 许用应力 [σ] | 600 MPa |

## 7. 多目标优化

### 7.1 打开优化对话框

**插件 → 齿轮多目标优化**（或工具栏按钮），弹出 `GearOptDialog`。

### 7.2 参数设置

**优化目标**（勾选启用，建议同时勾选前两项）：

| 目标 | 说明 |
|------|------|
| 最小化最大应力 σ_max | 提高齿轮强度可靠性 |
| 最小化质量 mass | 减轻主动轮重量 |
| 最小化传动比误差 | 有精确传动比要求时启用 |

**NSGA-II 超参数**：

| 参数 | 默认 | 说明 |
|------|------|------|
| 种群大小 N | 30 | 越大越稳定，计算量线性增加 |
| 最大代数 | 20 | 建议正式计算 ≥ 30 代 |
| 交叉概率 | 0.9 | — |
| 变异概率 | 0.1 | — |
| 输入扭矩 | 100 N·m | 加载在主动轮齿面 |
| 单点超时 | 600 s | — |

**设计变量空间（12 个）**：

| 变量 | 类型 | 默认范围 |
|------|------|----------|
| 模数 m | 离散 | {1.5, 2.0, 2.5, 3.0, 4.0} mm |
| Z₁, Z₂ | 整数 | [17, 50] / [17, 80] |
| 压力角 α | 离散 | {20°, 22.5°, 25°} |
| 变位系数 x₁, x₂ | 连续 | [−0.5, 0.8] |
| 修型量 Cₐ₁, Cₐ₂ | 连续 | [0, 0.05m] mm |
| 修型长度 Lₐ₁, Lₐ₂ | 连续 | [0, 0.3m] mm |
| 齿宽 B | 连续 | [10, 80] mm |
| 轮毂比 | 连续 | [0.3, 0.6] |

### 7.3 优化运行逻辑

```
① 拉丁超立方初始采样（N 个点，均匀覆盖变量空间）
        ↓
② 并行评估全部 pending 点（每点走 §6 单工况流程）
   进度条实时更新
        ↓
③ 非支配排序（fastNonDominatedSort）
   → Rank 1 = 当前 Pareto 前沿
        ↓
④ SBX 交叉 + 多项式变异 → 生成 N 个子代
        ↓
⑤ 约束修复（snapBounds：不根切、不变尖、齿数下限）
        ↓
⑥ 精英选择：父代 2N → 按 Deb 约束支配选最优 N 进入下一代
        ↓
⑦ 收敛判断
   ├─ 已达最大代数 → 停止
   ├─ 超体积连续3代变化 < 0.1% → 自动停止
   └─ 用户点击"停止" → 当前工况结束后停止
```

**进度展示示例**：

```
第 5/20 代 | 已完成 142/600 点 | Pareto 18 个
[0-003] σ=312 MPa  mass=1.24 kg  ✅ Done
[0-004] σ=—        mass=—         ❌ Failed (timeout)
```

## 8. 结果浏览与导出报告

### 8.1 结果浏览器

优化完成（或运行中）点击**查看结果**，打开 `GearOptResultViewer`。

**上方：设计点表格**

| 列 | 说明 |
|----|------|
| 代/ID | 第几代 · 第几个点 |
| Z₁, Z₂, m, α... | 12 个设计变量 |
| σ_max [MPa] | 齿根最大 von Mises 应力 |
| u_max [mm] | 最大节点位移 |
| mass [kg] | 主动轮质量 |
| 状态 | Done / Failed / Infeasible |
| ★ | Pareto 前沿标记 |

点击任意行 → 对应几何模型加载到 FastCAE 主视口。

**下方：Pareto 散点图**

- X 轴：σ_max [MPa]，Y 轴：mass [kg]
- 蓝色点：全部可行解；橙色点：Pareto 前沿
- 悬停显示设计点参数 tooltip

### 8.2 导出 CSV 报告

点击**导出 CSV**，生成如下格式文件：

```
文件名：optimization_history_<timestamp>.csv
编码：UTF-8
```

字段：

```
gen, id, z1, z2, module, alpha, x1, x2, ca1, lca1, ca2, lca2,
width, hubRatio, sigmaMax_MPa, uMax_mm, mass_kg, status, errorMsg
```

属于 Pareto 前沿的行末列附 `,PARETO` 标记。

> Excel 打开 CSV 时请选择：数据 → 从文本/CSV → 编码选 UTF-8。

### 8.3 最优几何导出 STEP

结果表格中选中目标设计点 → 右键**导出 STEP**，将几何保存为 `.stp` 文件，可导入其他 CAD 系统。

## 10. 常见问题

**Q：建模后视口无显示**

检查 `extlib/` 中 OCC 库是否完整（首次编译需从 gitee clone，约 2 GB）。

**Q：提示找不到 ccx.exe**

按第 3.2 节设置 `CCX_PATH` 环境变量，或将 `ccx.exe` 放到 `tools/calculix/`。验证：

```powershell
python test\manual\failure_injection_test.py
# 期望：ALL_TESTS_DONE，exit=0
```

**Q：单点求解 Failed / 超时**

查看 `runs/{gen}_{id}/job.sta` 了解收敛情况。可增大 `timeoutSeconds`（配置面板），或在调试模式下勾选"保留工作目录"手动查看 CCX 日志。

**Q：NSGA-II 收敛太慢**

- 增大种群（N ≥ 50）并增加代数（≥ 30）
- 已知大致最优区域时可缩小变量范围
- 先用 N=20、5 代做快速预探再正式跑

**Q：CSV 文件在 Excel 中显示乱码**

CSV 采用 UTF-8 编码。Excel 打开时选：**数据 → 从文本/CSV → 文件原始格式选 65001 (UTF-8)**。

**Q：编译报 C2429（结构化绑定需要 /std:c++17）**

确认 `src/GearAutoOpt/CMakeLists.txt` 中存在：

```cmake
set_target_properties(GearAutoOpt PROPERTIES CXX_STANDARD 17 CXX_STANDARD_REQUIRED ON)
```

新增的测试目标也需在各自的 `set_target_properties` 中加 `CXX_STANDARD 17`。
